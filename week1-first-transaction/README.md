# Неделя 1. Вход в Web3: первая транзакция в Solana

**Задание:** создать кошелёк, получить тестовый SOL, отправить первую транзакцию, найти и разобрать её в Solana Explorer.

## Что сделано

`first-transaction.ts`:

1. **Кошелёк.** Генерирует пару ключей ed25519 и сохраняет её в `wallet.json` (в архив не входит: это секретный ключ).
2. **Тестовые SOL.** Запрашивает airdrop в devnet. Если faucet упёрся в лимит, пополняет кошелёк с основного devnet-кошелька.
3. **Транзакция.** В одной транзакции две инструкции:
   - `SystemProgram.transfer`: перевод 0.05 SOL;
   - Memo Program: текст `Week 1: my first Solana transaction`.
4. **Разбор.** `getParsedTransaction` возвращает те же данные, что показывает Explorer: slot, время блока, комиссию, аккаунты с ролями (signer/writable), изменения балансов, инструкции и логи программ.

Результат с реальной подписью и ссылкой на Explorer лежит в `result.json`.

## Разбор транзакции (как в Explorer)

- **Fee payer** — первый аккаунт, подписант. С него списываются 0.05 SOL и комиссия 5000 лампортов.
- **Получатель** — writable, не подписант: его баланс вырос на 0.05 SOL.
- **System Program** `11111111111111111111111111111111` — выполнил инструкцию `transfer`.
- **Memo Program** `MemoSq4gq...` — записал текст в логи (`Program log: Memo ...`).
- Комиссия 0.000005 SOL = 5000 лампортов за одну подпись.
