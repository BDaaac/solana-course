# Неделя 14. Capstone: Liquidity Vault (вариант А)

**Задание:** веб-интерфейс с подключением кошелька, тесты и README.

## Что сделано

- **Веб-интерфейс:** [`../liquidity-vault/app`](../liquidity-vault/app) (Vite + React + `@solana/wallet-adapter`, Phantom/Solflare в режиме devnet):
  - подключение кошелька;
  - баланс пользователя, его share-токены, внесённая сумма, сколько всего в vault, цена одного share;
  - кнопки **«Внести»** и **«Вывести»** (при первом депозите создаются ATA share-токена и карточка — одной транзакцией);
  - статус транзакции со ссылкой на Solana Explorer;
  - блок администратора (виден только admin): пауза и `sync_balance`.
- **Что не вынесено в браузер:** swap, открытие/закрытие позиции и сбор комиссий выполняются скриптами (`npm run vault:swap`, `npm run vault:position`): им нужен расчёт ликвидности и tick-массивов через Raydium SDK. Страница администратора для этих операций не сделана.
- **Тесты:** интеграционные сценарии на devnet — [`scripts/01…04`](../liquidity-vault/scripts). Каждый сам проверяет результат (суммы shares/вывода, отрицательные сценарии: ноль, чужой админ, повторная карточка, пауза, slippage) и падает при расхождении. Юнит-тестов программы (LiteSVM) нет.
- **README:** [`../liquidity-vault/README.md`](../liquidity-vault/README.md) — что делает продукт, как запустить, адреса в devnet, схема аккаунтов.

## Запуск интерфейса

```bash
cd liquidity-vault/app
npm install
npm run dev     # http://localhost:5173
```

Откройте Phantom/Solflare в режиме **devnet**. Чтобы вносить токены, нужны токены VLT на кошельке; токен создан кошельком админа (mint authority), для демо токены отправляются на кошелёк демонстранта (скрипт `01-vault.ts` минтит токены админу и тестовому пользователю).
