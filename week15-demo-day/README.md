# Неделя 15. Solana Demo Day (РК2)

Сценарий выступления 5–7 минут: **Liquidity Vault**. Живой прогон не выполнялся; ниже — план и готовые материалы.

## Структура

| Время | Блок | Что говорим / показываем |
|---|---|---|
| ~1 мин | Проблема | Обычный пользователь не умеет подбирать диапазон и следить за ценой в концентрированной ликвидности. Деньги в узком диапазоне зарабатывают больше, но требуют постоянного внимания. |
| ~1 мин | Решение | Vault собирает токены в общий котёл и выдаёт share-токены (долю). Админ/бот размещает котёл в CLMM-пуле Raydium и переставляет диапазон. Почему блокчейн: средства принадлежат PDA программы — ни администратор, ни кто-то другой не может забрать их подписью; доли — обычные токены. |
| 3 мин | Live demo | кошелёк → внести ([интерфейс](../liquidity-vault/app)) → swap (`npm run vault:swap`) → открыть позицию → собрать комиссии → закрыть → вывести (последние шаги — `npm run vault:position` и интерфейс) |
| ~1 мин | Как устроено | Схема аккаунтов ([README](../liquidity-vault/README.md)), транзакция вывода в Explorer с inner instructions `burn` + `transfer` |
| ~30 сек | Что дальше | Автоматический вывод (закрытие позиции по запросу), keeper-бот для ребалансировки, комиссия управления, несколько пулов, mainnet-аудит |

## Подготовка

- Прогнать демо целиком хотя бы дважды накануне; заранее пополнить демо-кошелёк SOL и токенами VLT.
- Записать видео на случай сбоя сети.
- Распределить роли: кто рассказывает, кто показывает (в моём случае выступаю один).

## Ответы на вопросы жюри

- **Почему share-токенов выдаётся меньше, чем внесено токенов?** Share-токен подорожал после заработка vault: `shares = вклад × total_shares / total_tokens`. Пример на devnet: 110 токенов → 100 shares при цене 1,1.
- **Кто может распоряжаться средствами в vault?** Только программа: хранилище токенов и share-mint принадлежат PDA. Администратор лишь запускает разрешённые операции (swap, позиция) с проверками (`Unauthorized`, `min_amount_out`, `amount_*_max`).
- **Зачем при обмене задаётся минимум?** Защита от slippage: если за время прохождения транзакции цена сдвинулась, обмен откатывается. В devnet показан отклонённый обмен: ошибка `TooLittleOutputReceived`.
- **На чём vault зарабатывает?** На комиссиях (0,05 % с каждого обмена в пуле) от ликвидности, размещённой в выбранном диапазоне. На devnet заработано 0,031 VLT + 0,031 QTE на тестовых объёмах — это демонстрация механики, не показатель доходности.
